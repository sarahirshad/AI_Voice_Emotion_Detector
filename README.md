# AI Voice Emotion Detector

An AI/ML project that detects human emotions (happy, sad, angry, calm, etc.)
from short audio recordings using Python, librosa, and scikit-learn.

## Folder Structure
- data/        → Raw audio dataset
- models/      → Trained ML models
- app/         → Streamlit app
- notebooks/   → Optional Jupyter notebooks
- src/         → Feature extraction and training code
